# DESIGN SYSTEM: Pull Store Minimalist Modern

## 1. Filosofi Visual
- **Zero Visual Clutter:** Desain bersih ala Vercel/Linear, *whitespace* lega, dan garis batas tipis (`1px solid`).
- **Brand Identity:** Nama **Pull Store** merepresentasikan gabungan nama pendiri dan istilah teknis (`git pull`).

## 2. Aturan Ketat Palet Warna (Maksimal 3 Warna)
1. **Primary (Background & Surface - 60%):**
   - Canvas: `#FAFAFA` (`bg-zinc-50`)
   - Card Surface: `#FFFFFF` (`bg-white`)
   - Border: `#E4E4E7` (`border-zinc-200`)
2. **Sub (Typography - 30%):**
   - Heading / Main Text: `#09090B` (`text-zinc-950`)
   - Muted Text: `#52525B` (`text-zinc-600`)
3. **Sub-Sub (Accent & Interactive - 10%):**
   - Primary Accent: `#2563EB` (`bg-blue-600` / `text-blue-600`)
   - Hover Accent: `#1D4ED8` (`hover:bg-blue-700`)
   - Soft Background: `#EFF6FF` (`bg-blue-50`)

## 3. Aturan Tipografi
1. **Primary UI Font:** `Plus Jakarta Sans` atau `Inter` (`font-sans`).
2. **Monospace Font:** `JetBrains Mono` (`font-mono`) khusus untuk Harga (Rp), Badge Durasi, dan Tech Stack.
